# Playable Web Game Showcase Specifications (`gaoyaguo.eu.cc` Roster)

This reference outlines the technical specifications, mechanics, and visual packaging of the 8 signature games featured on the `gaoyaguo.eu.cc` universe.

---

## Game Roster & Technical Blueprints

### 1. QQ 飞车 3D (Speed Racing 3D)
- **Tech Stack**: Three.js / WebGL / Cannon.js (Physics)
- **Visual Style**: Cyberpunk neon speedway, volumetric rain, vehicle nitro trails.
- **Cinematic Anchor**: Low asphalt camera skimming track, 360-degree drift follow cam.
- **Audio Profile**: High-energy synthwave, engine revs, tire screeching, nitro burst.

### 2. 穿越火线 · 运输船 (CrossFire: Transport Ship WebGL)
- **Tech Stack**: Three.js First-Person Controller, PointerLock API
- **Visual Style**: Industrial cargo ship, metallic containers, container catwalks, muzzle flash.
- **Cinematic Anchor**: Tactical first-person weapon inspection, crane aerial establishing shot.
- **Audio Profile**: AK-47 gunshot acoustics, container metallic footsteps, radio chatter.

### 3. CF 网页对战 (CF Tactical Arena 2D/Canvas)
- **Tech Stack**: HTML5 Canvas, WebSocket multiplayer state sync
- **Visual Style**: Retro arcade pixel/isometric tactical shootout.
- **Audio Profile**: Retro 8-bit bullet sounds, reload clicks, victory fanfare.

### 4. LOL · 海克斯大乱斗 (Hextech ARAM Arena)
- **Tech Stack**: PixiJS / 2.5D Isometric Canvas
- **Visual Style**: Arcane Hextech glowing crystals, magical particles, ornate runic bridges.
- **Cinematic Anchor**: Sweeping isometric crane shot across the bridge abyss.
- **Audio Profile**: Hextech humming, arcane spell impacts, crowd cheering.

### 5. 黑神话悟空 · 虎先锋 (Black Myth Wukong: Tiger Vanguard Boss Trial)
- **Tech Stack**: Babylon.js / WebGL 3D Action Arena
- **Visual Style**: Ancient crimson temple, blood pool floor reflections, dark fantasy oriental mythology.
- **Cinematic Anchor**: Low Dutch angle booming up to tiger roar, sword clash freeze-frame.
- **Audio Profile**: Traditional Chinese drums, blade unsheathing, deep guttural beast roar.

### 6. EVENSONG (晚歌 · 治愈独立探险)
- **Tech Stack**: CSS 3D & HTML5 Canvas Ambient Adventure
- **Visual Style**: Low-poly pastel twilight, fireflies, minimalist silhouettes.
- **Cinematic Anchor**: Slow tranquil dolly tracking across grassy meadows into sunset.
- **Audio Profile**: Gentle acoustic piano and environmental wind/cricket ambience.

### 7. 双人成行 · 大肥鱼版 (It Takes Two: Fat Fish Cooperative)
- **Tech Stack**: Dual-input cooperative HTML5 Canvas physics game
- **Visual Style**: Whimsical cartoon underwater fantasy, bubbly physics, oversized plush fish.
- **Cinematic Anchor**: Split-screen synchronized zoom, water splash slow motion.
- **Audio Profile**: Playful marimba melodies, comical water pops, spring boings.

### 8. 鹈鹕骑自行车 (Pelican on a Bicycle · 极简魔性小游戏)
- **Tech Stack**: Lightweight Matter.js physics sandbox
- **Visual Style**: Hand-drawn doodle aesthetics, bouncy suspension animations.
- **Cinematic Anchor**: Side-scrolling camera tracking wobbly bicycle trajectory.
- **Audio Profile**: Squeaky bicycle horn, frantic pedaling sound, comical wipeout crash.
